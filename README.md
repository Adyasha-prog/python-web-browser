# Python Web Browser

A simple desktop web browser built with Python and PyQt5. It provides a basic browser interface for opening websites and navigating the web.

## Features

- Open and browse websites
- Enter URLs using the address bar
- Back, Forward, Refresh, and Home buttons
- Bookmark toolbar
- Quick links to GitHub, Facebook, LinkedIn, Instagram, and Twitter
- Displays the current webpage URL

## Technologies

- Python
- PyQt5
- PyQtWebEngine

## Installation

Install the required packages using:

```bash
pip install -r requirements.txt
```

## Run the Project

Open the project folder in a terminal and run:

```bash
python main.py
```
